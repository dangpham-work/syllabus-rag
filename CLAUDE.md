# syllabus-rag

## Quy tắc Git

- **Không thêm AI làm cộng sự** khi commit/push lên GitHub: không dòng `Co-Authored-By: Claude ...`, không dòng "Generated with Claude Code" trong commit message hay mô tả PR. Tác giả chỉ là thành viên nhóm.
- Tên nhánh theo cấu trúc tuần 1: `feature/<tên>-tuan<N>-<tầng>` (ví dụ `feature/long-tuan2-data`).
- Commit theo Conventional Commits, mô tả bằng tiếng Việt: `feat(data): ...`, `docs(...): ...`.
- Không commit trực tiếp vào `main`; mở PR để TV1 duyệt và merge.
